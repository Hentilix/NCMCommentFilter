# BetterNEM：专辑评论过滤（第一阶段）

按当前网易云账号的**用户黑名单 ID**隐藏专辑热评、最新评论、滚动加载评论和评论内的被回复内容。右下角提供开关、刷新黑名单和当前页面隐藏数量。关闭开关立即恢复，移除插件并重载后不留下过滤样式。

本阶段只有评论过滤，没有歌单播放、站外评分或手动名单。

## 当前状态

2026-10-18 首次验收、2026-10-19 最终复核：已在本机 **网易云音乐 3.1.41.205529（64 位）＋ BetterNCM 1.3.4 ＋ 热更新 83304b1** 中完成主要功能验收：

- 使用客户端原生接口自动读取当前账号黑名单，多次读取均返回 6 位用户。
- 《The Sophtware Slump》的热评及最新评论，滚动检查了 85 条去重评论。命中的 1 条评论在热评和最新评论中重复出现时均被隐藏，未发现正常评论误隐藏。
- 开关、手动刷新、动态列表和停用恢复已在真实客户端检查。
- 本专辑没有黑名单用户的真实回复；回复过滤通过浏览器自动测试，以及真实客户端中使用原生回复结构和已同步名单构造的临时本地样本验证。没有修改或发布服务器评论。

详细证据、测试边界见 [验收记录](docs/acceptance-2026-10-18.md)。此前“BetterNCM 无法注入”的结论已纠正：当时关闭窗口没有结束托盘中的旧进程；本次完整退出后，官方加载器可以正常工作。

## 安装与使用

**本机已安装 BetterNCM，勿重复覆盖官方加载器。** 最终插件包位于 `dist\betternem-comment-filter.plugin`。

1. 在 BetterNCM 中打开插件文件夹，将插件包放到其 `plugins` 目录。本机是 `C:\betterncm\plugins\betternem-comment-filter.plugin`。更新时覆盖同名包，不要再放一份到 `plugins_dev`。
2. 使用 BetterNCM 的“重启并重载插件”，或从网易云托盘菜单**退出程序**再启动。仅关闭窗口可能只是最小化到托盘。
3. 打开专辑的“评论”标签。面板应显示“已同步 N 位黑名单用户”。右下角开关可即时恢复/过滤；“刷新黑名单”会重新调用网易云接口。
4. 黑名单只在内存中保存。重新打开客户端、切换账号会重新读取；修改网易云黑名单后可点击刷新。持久化的只有过滤开关。
5. 停用：在 BetterNCM 管理器删除本插件并重载，或退出客户端、移除本插件包后重启。无需卸载 BetterNCM 或改动网易云安装文件。

未安装 BetterNCM 的其他机器可参考 [官方安装说明](https://github.com/std-microblock/chromatic/wiki/%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E)；下载文件保留在 `dist`。本机的安装与验收已完成，无需再次下载。

## 兼容与失败状态

- 只允许客户端 `3.1.41.205529`，并分别适配已检查的资源版本 `c6406e5`（安装包基线）和 `83304b1`（本机实际运行的热更新）。真实登录验收使用后者。
- 未知客户端/热更新会显示“未验证”；未登录、网络失败、超时会明确显示原因并恢复评论，不使用旧账号名单或固定名单。
- 客户端更新可能改变内部接口。未知版本会停止过滤，需重新核对接口并发布适配；不能只修改版本号绕过检查。
- 不能识别评论作者或回复结构时会提示部分无法读取，保留无法识别的内容。不要将错误状态下的“隐藏 0 条”当作同步成功。
- 隐藏计数指**当前挂载在专辑页面中的评论/回复**，被隐藏的父评论计一次。网易云使用虚拟列表，滚动移出页面的条目不累计，因此计数可能变化。

## 本地验证与打包

```powershell
npm ci
npm test
npm run test:browser
python scripts/check_client.py
python scripts/build_plugin.py
```

浏览器测试需要 Windows Chrome；可用 `BETTERNEM_BROWSER` 指定其他 Chromium 浏览器路径。插件没有运行时第三方依赖。Playwright 只用于开发测试。

`check_client.py` 只检查本地安装包基线，不代表运行时热更新，也不代表已登录账号实测。打包脚本只包含 `manifest.json` 和 `main.js`，不包含开发工具或验收数据。

## 实现与隐私

通过 BetterNCM 的 `Main` 注入入口运行，使用其传入的局部 `plugin` 对象注册初始化。自动读取账号 `host.uid`，调用目标客户端原生 `/api/blacklist/get`，从评论 React 数据中读取 `user.id` 和 `beReplied[].user.id`，不依赖昵称。

请求由网易云客户端管理登录会话；插件不读取密码或复制 Cookie，不上传账号凭据或黑名单到第三方，也不保存名单到磁盘。黑名单接口在目标版本禁用缓存，手动刷新会重新请求。

仅过滤专辑主内容区，避免影响播放器的歌曲评论。DOM 观察器在浏览器绘制前处理新卡片和文字更新；仅初始化、刷新或开关等操作扫描整个评论区，没有高频全页轮询。首次同步期间暂时隐藏专辑评论，最长等待 10 秒；失败即恢复。账号变化通过客户端状态订阅感知，另有 30 秒账号检查作为补充。
