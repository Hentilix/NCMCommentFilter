# NCMCommentFilter：专辑与单曲评论过滤

按当前网易云账号的**用户黑名单 ID**过滤专辑和单曲的热评、最新评论、滚动加载评论及评论内的被回复内容。被过滤的评论不会在虚拟列表中留下空白。页面提供开关、刷新黑名单入口和当前隐藏数量；关闭开关后评论恢复显示。

插件只提供评论过滤，没有歌单播放、站外评分或手动名单。

## 安装与使用

1. 按 [BetterNCM 官方安装说明](https://github.com/std-microblock/chromatic/wiki/%E4%BD%BF%E7%94%A8%E8%AF%B4%E6%98%8E) 安装 BetterNCM。
2. 将 [`dist/ncm-comment-filter.plugin`](dist/ncm-comment-filter.plugin) 放入 BetterNCM 的 `plugins` 目录。更新时替换同名文件。
3. 完全退出并重新启动网易云音乐，或使用 BetterNCM 的“重启并重载插件”。仅关闭窗口可能会将程序留在托盘。
4. 打开专辑或单曲评论区，也可打开播放器中的单曲评论面板。过滤面板会显示黑名单同步状态、本页隐藏数量、开关和“刷新黑名单”按钮。
5. 修改网易云黑名单后，点击“刷新黑名单”。切换账号后插件会读取新账号的名单。

从旧名 NEMCommentFilter 升级时，请先移除 `plugins` 目录中的 `betternem-comment-filter.plugin` 或 `betterncm-comment-filter.plugin`，再安装新包，避免两个版本同时加载。原有过滤开关设置会继承。

面板标题可以拖动；点击右上角“−”会将面板收起成“+”黑框，点击“+”重新展开。收起后的黑框也可以拖动，过滤功能会继续运行。

停用时可在 BetterNCM 管理器中移除插件并重载，或退出网易云音乐、移除插件包后重新启动。

`docs/acceptance-*.md` 是历史验收记录，其中保留验收当时使用的旧项目名和安装路径。

## 兼容与失败状态

- 支持网易云音乐 Windows 桌面端 `3.1.42.205594`（运行时资源标识 `14827e8`，安装包资源文件名使用 `1482700000000`），同时保留 `3.1.41.205529`（资源版本 `c6406e5` 和 `83304b1`）支持。客户端更新后可能需要适配。
- 未知客户端或资源版本会显示“未验证”；未登录、网络失败或读取超时会明确显示状态并恢复评论。插件不会改用固定名单或旧账号名单。
- 无法识别评论作者或回复结构时会提示部分无法读取，并保留无法识别的内容。
- 隐藏计数只统计当前页面中仍挂载的评论和回复。网易云使用虚拟列表，滚动后计数可能变化。

## 实现与隐私

插件通过 BetterNCM 的 `Main` 注入入口运行，使用客户端原生 `/api/blacklist/get` 读取当前账号黑名单，按评论数据中的 `user.id` 和 `beReplied[].user.id` 匹配，不依赖昵称。

请求由网易云客户端管理登录会话。插件不读取密码或复制 Cookie，不向第三方上传账号凭据或黑名单，也不将黑名单保存到磁盘。只有过滤开关会持久化。

过滤范围限于专辑、单曲评论页及播放器的单曲评论面板。首次同步期间会暂时隐藏这些评论，以减少评论短暂出现后再消失；读取失败时会恢复显示。客户端的最新评论使用虚拟列表，插件会在隐藏或恢复评论时重新测量列表行高，消除原先的空白占位。后续仅处理变化的评论节点。
